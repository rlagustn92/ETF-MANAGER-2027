# ⚽ ETF MANAGER 2027

FM(풋볼 매니저) 전술판에서 영감을 받은 **포트폴리오 전술 도구 + 실제 매수계획 계산기 +
현금흐름(분배금) 계산기 + 초간단 Buy & Hold 백테스트**.

미국/한국 주식·ETF를 축구 선수처럼 축구장에 자유롭게 배치하고,
초기자본과 목표비중을 넣으면 **실제 매수 가능한 정수 주식 수량 / 실제 투자금 / 잔여 현금 /
월·연 예상 분배금 / 예상 현금수익률** 을 계산합니다. 특정 과거 시작일부터의 단순 수익률도 확인할 수 있습니다.

> 이 프로그램은 **포트폴리오 구성·계산 도구**입니다. 종목 점수·매수/매도 추천·시장 예측을 하지 않습니다.

필요: Python 3.11+ (개발·검증 환경 3.13)

```bash
cd etf_manager

```

## 2. 실행

```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 이 열립니다.

## 3. 기본 사용 시나리오

1. 상단에서 **초기자본**(원) 입력 — 어떤 금액이든 가능
2. 왼쪽 **종목 검색**에 `QQQ`, `삼성전자`, `005930` 등 입력 → **검색** → `＋` 버튼으로 추가
3. 추가된 카드를 **전술판(세로) 위 원하는 포지션 슬롯으로 드래그** — FM처럼 슬롯에 스냅됩니다.
   같은 슬롯에 다른 종목이 있으면 서로 자리가 바뀝니다(스왑). 아래=우리 진영(골키퍼), 위=공격 방향
4. 왼쪽 **보유 종목 · 목표비중**에서 각 종목의 목표비중(%) 입력 후 Enter/Tab
   - 합계가 100%를 넘으면 오류 표시, 100% 미만은 나머지를 현금으로 처리
5. 가운데/아래에서 자동 계산 결과 확인
   - 정수 주식 수량 = `floor(목표금액 ÷ 1주 원화가격)` (목표금액을 초과하지 않음)
   - 실제 투자금 / 잔여 현금 / 실제비중
   - 월·연 예상 분배금 / 예상 현금수익률
6. 카드를 **클릭**하면 오른쪽에 상세정보 + 분배금 설정 + 종목 제거

## 4. 데이터 업데이트

화면 아래 **🔄 데이터 업데이트** 버튼을 누르면 가격·환율·분배금 캐시를 비우고
다시 최신 데이터를 가져옵니다. 코드를 수정할 필요가 없습니다.

- **데이터 기준일**: 사용한 일별 종가의 날짜
- **마지막 업데이트**: 화면을 마지막으로 다시 계산한 시각
- 캐시 만료: 가격 6시간 / 최신가 15분 / 환율 1시간 / 분배금 12시간 (`config.py` 에서 조정)

## 5. 전술 저장 / 불러오기

- **💾 전술 저장 (JSON)**: 현재 전술(전술명·초기자본·종목·비중·좌표·분배금 설정)을 JSON 파일로 내려받기
- **📂 전술 불러오기 (JSON)**: 저장한 JSON 업로드. 잘못된 파일이면 앱이 죽지 않고 오류 메시지만 표시

JSON 예시는 [`tactics/sample_monthly_income.json`](tactics/sample_monthly_income.json) 참고.

## 6. 백테스트 (단순 Buy & Hold)

화면 아래 **📈 백테스트** 펼치기 → 시작일 / 초기 투자금 / (선택) 분배금 포함 → **백테스트 실행**

- 시작일에 **과거 종가**로 매수, 이후 **리밸런싱 없음**, 최신 데이터 기준일에 평가
- 시작일이 거래일이 아니면 **이후 첫 거래일**로 이동 (입력일·실제 매수일 모두 표시)
- 시작일보다 **늦게 상장된 종목**이 있으면 백테스트 불가로 안내
- 미국 종목은 **그 시점의 과거 환율**로 환산 (과거 주가 + 현재 환율 조합을 쓰지 않음)
- 주식분할: yfinance/FDR 종가가 이미 분할을 소급 반영하므로 보유수량에 분할비율을 추가로 곱하지 않음
- 분배금 포함 옵션: 분배금을 **현금으로 수령**(재투자 없음)해 합산
- 수수료·세금·슬리피지·환전비용은 **반영하지 않음**

## 7. 연도 변경 (2027 → 2028)

[`config.py`](config.py) 의 **한 줄만** 수정합니다.

```python
APP_YEAR = 2028
```

화면 제목, 브라우저 탭 제목, 저장 파일명 등 모든 명칭이 `ETF MANAGER 2028` 로 바뀝니다.
다른 파일은 건드릴 필요가 없습니다. (테스트: `tests/test_config_year.py`)

## 8. 문제 해결

| 증상 | 원인 / 조치 |
|---|---|
| 특정 종목이 `데이터 없음` | 해당 소스에서 가격/분배금을 못 가져옴. 다른 종목은 정상 동작. 상세 패널의 **수동 가격 입력** / 분배금 **직접 입력** 사용 |
| `USD/KRW: 데이터 없음` | 환율 소스 일시 오류. **🔄 데이터 업데이트** 재시도 |
| 한국 종목 분배금이 안 나옴 | 한국 분배금은 자동 확보가 불안정. 상세 패널에서 **분배금 계산 방식 → 직접 입력** |
| 백테스트 `상장 이후` 메시지 | 시작일보다 늦게 상장된 종목 포함. 시작일을 늦추거나 해당 종목 제외 |
| 검색 결과 없음(미국) | 정확한 티커를 입력하면 yfinance 로 실시간 확인 시도 |
| 값이 추정으로 채워지는 것 아닌가? | 아닙니다. 데이터가 없으면 계산에서 제외하고 `데이터 없음`으로 표시합니다 |

## 9. 데이터 출처

| 항목 | 소스 |
|---|---|
| 미국 가격/분배금/분할 | Yahoo Finance (`yfinance`) — `history(auto_adjust=False)` 로 실제 종가/조정종가 분리 |
| 한국 가격 | `FinanceDataReader` (KRX 기반, 수정주가) |
| 한국 종목/ETF 목록(검색) | `FinanceDataReader` `StockListing("KRX")`, `StockListing("ETF/KR")` |
| USD/KRW 환율 | `yfinance` `USDKRW=X` → 실패 시 `FinanceDataReader` `USD/KRW` |
| 한국 분배금 | `yfinance` 한국 심볼(`.KS`/`.KQ`) 보조 시도 → 없으면 수동 입력 |
